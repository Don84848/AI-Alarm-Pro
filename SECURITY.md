## 🔒 Reporting a Vulnerability

We take the security of **AI Alarm Pro** seriously. If you believe you have found a security vulnerability, please follow responsible disclosure guidelines:

1. **Do not create a public GitHub issue.**
2. Send an email to the repository owner at `awaisdon5555555@gmail.com` with:
   - A description of the issue.
   - Steps to reproduce or proof-of-concept.
   - Potential impact of the vulnerability.
3. We will respond within 48 hours to acknowledge your report and coordinate a patch.

---

## 🛡️ User Privacy & API Keys
* **Client-Side Privacy:** Google Gemini API keys entered by users are stored strictly on-device in `localStorage`.
* **Zero Telemetry / Zero Secret Leakage:** No keys or personal scheduling data are ever transmitted to any third-party server other than direct client-to-Google API calls.
