# Contributing to AI Alarm Pro

Thank you for your interest in contributing to **AI Alarm Pro**! We welcome contributions from developers, designers, and testers worldwide.

---

## 🛠️ Getting Started

### Prerequisites
- Node.js 18 or higher
- npm 9 or higher
- (Optional) Android Studio for native Android testing

### Development Setup
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/your-username/AI-Alarm-Pro.git
   cd AI-Alarm-Pro
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open `http://localhost:3000` in your browser.

---

## 🌿 Branching & Git Workflow

1. Create a feature branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make your changes adhering to TypeScript, React, and Tailwind CSS best practices.
3. Verify the build passes cleanly:
   ```bash
   npm run build
   ```
4. Commit your changes using conventional commit messages:
   ```bash
   git commit -m "feat: add snooze customization option"
   ```
5. Push to your fork and submit a Pull Request against the `main` branch.

---

## 🔒 Security & Privacy Notice
* **Never commit API keys or private credentials.**
* The app is designed to store API keys exclusively in the user's local browser or device storage (`localStorage`).
